# Сайт магазина кроссовок — Энгельс

Адаптивный статический сайт без сборщика и сторонних библиотек.

## Структура
- `index.html` — главная страница
- `styles.css` — оформление и мобильная адаптация
- `script.js` — открытие фотографий в увеличенном виде
- `assets/` — 8 исходных фотографий обуви

Все восемь фотографий скопированы без изменения размеров и без повторного сжатия.

## Публикация на GitHub Pages
1. Загрузите все файлы и папку `assets` в корень репозитория.
2. Откройте Settings → Pages.
3. В Build and deployment выберите Deploy from a branch.
4. Выберите ветку `main` и папку `/ (root)`, затем Save.
